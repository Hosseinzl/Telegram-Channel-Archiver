Build a Python Telegram bot using aiogram v3 (async) and MongoDB (Motor async driver).

The bot is a content management and publishing system that:

Fetches raw news posts from a MongoDB collection called messages.

Only handle file types: photo_file_ids, video_file_ids, video_note_file_ids, voice_file_ids, audio_file_ids, document_file_ids.

Ignore other types like sticker, poll, web_page.

Functional Requirements

Poll the messages collection every 60 seconds for new posts.

Insert them into an internal MongoDB collection for state management.

Posts can be:

Single-file: send with caption and inline keyboard directly.

Album: send using sendMediaGroup with caption only on the first media. Then send a separate control message with inline keyboard.

Inline keyboard buttons:

Text Tools:

AI edit (placeholder)

Clean text (placeholder)

Shorten text (placeholder)

Expand text (placeholder)

Reset to original_text

Media Tools:

Toggle media selection

Toggle cover requirement (calls placeholder method generate_cover(file_id))

Publishing:

Publish to multiple channels

Provide placeholder methods:

async def ai_edit_text(self, post_id): ...

async def generate_cover(self, file_id): ... (download file, placeholder for cover API, return new file_id)

Users can reply to bot messages to edit text; bot must edit the original message, never resend old posts.

State management in internal collection:

original_text, current_text

selected_media (file_ids)

needs_cover

published_channels

album_message_ids

control_message_id

created_at, updated_at

After bot restart:

Reload posts from internal collection

Must still be able to edit messages sent before crash (persist message_ids for at least 24h)

Extra Notes

When sending posts to channels, use selected_media only.

Only the first media item of albums can have captions edited later.

Cover generation and AI editing methods are placeholders — do not implement actual logic, only method stubs.
